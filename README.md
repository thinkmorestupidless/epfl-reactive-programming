# epfl-reactive-programming

Assignments from EPFL's "Principles of Reactive Programming" course (EdX/Coursera, taught by Martin Odersky, Erik Meijer, and Roland Kuhn).

- **`actorbintree`** - an actor-based binary tree set, implementing insert/contains/remove with Akka actors handling garbage collection of removed nodes.
- **`example`** - the course's starter/example assignment.
